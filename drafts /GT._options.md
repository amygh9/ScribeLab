Die Sterilisation ist ein validiertes Verfahren.
Sie dient der Sicherstellung der Sterilität.
Dabei werden Mikroorganismen inaktiviert.

Vor dem Prozess erfolgt die Reinigung.
Ein Reinigungsmittel wird verwendet.
Die Reinigung kann manuell oder automatisch erfolgen.

Danach folgt die Desinfektion.
Es werden Desinfektionsmittel eingesetzt.
Die Desinfektionszeit ist entscheidend.
Auch die Desinfektionstemperatur ist wichtig.

Die mikrobielle Belastung wird bestimmt.
Diese wird als Bioburden bezeichnet.
Eine bakterielle Belastungsprüfung wird durchgeführt.
Dabei werden koloniebildende Einheiten gezählt.

Der Sterilisationsprozess läuft in einer Kammer ab.
Die Kammer wird vorgewärmt.
Die Kammer-Referenztemperatur wird erreicht.

Wichtige Parameter sind Temperatur und Haltezeit.
Auch die Luftfeuchte wird überwacht.
Die relative Luftfeuchte hat Einfluss auf den Prozess.

Es gibt eine Warngrenze.
Es gibt auch eine Eingriffsgrenze.
Diese Grenzen dienen der Steuerung.

Biologische Indikatoren werden eingesetzt.
Auch chemische Indikatoren werden verwendet.
Das Chemo-Indikatorsystem zeigt den Endpunkt.

Die Dosimetrie wird bei Bestrahlung verwendet.
Ein Dosimeter misst die Dosis.
Die Dosisverteilung wird bestimmt.

Ein geschlossener Bereich wird verwendet.
Ein aseptischer Arbeitsbereich ist notwendig.
Aseptische Technik wird angewendet.

Kontamination kann intrinsisch sein.
Kontamination kann extrinsisch sein.
Beide müssen vermieden werden.

Die Kalibrierung der Geräte ist wichtig.
Die Messgenauigkeit wird überprüft.
Die Messpräzision wird sichergestellt.
Die Messunsicherheit wird bewertet.

Filter werden eingesetzt.
Eine Filterintegritätsprüfung wird durchgeführt.

Der Prozess hat einen definierten Zyklus.
Es gibt eine Aufbaudauer.
Es gibt eine Abbaudauer.
Die Zykluszeit wird gemessen.

Am Ende erfolgt die Dokumentation.
Alle Parameter werden überprüft.
Der Prozess wird validiert.

Der Prozess wird durch eine automatische Steuerung überwacht.

Die Zykluszeit wird dokumentiert und ausgewertet.
